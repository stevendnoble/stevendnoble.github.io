When can I download Word Menagerie?

Word Menagerie is coming soon to iPhone. This page will have the App Store link when the game is available.

How do free plays and hints work?

Each game has five free solo plays per day. The five daily hints are shared across the collection. Free allowances refresh at local midnight and do not carry over. Multi-round games count as one run, not one play per internal round.

Can I finish a saved game after using my plays?

Yes. Continuing an unfinished saved game does not use another play. Restarting the same unfinished puzzle is free; starting a fresh run or replaying a completed puzzle uses a play. Letter Duel and Cross Clash currently do not save unfinished solo boards after you leave their screens.

How do I restore my full-game unlock?

Open Purchase from the app’s home screen and choose Restore purchases. Use the Apple Account that originally obtained the unlock. Free allowances are separate on each device; purchase ownership can be restored.

How do I redeem an offer code?

Open Purchase and choose Redeem code to use Apple’s redemption screen. An eligible full-game code gives you the permanent unlock. Availability and redemption deadlines are set by the offer.

Do I need an account or internet connection?

Solo games use word lists and puzzles bundled with the app. You do not need a separate Word Menagerie account. Multiplayer uses Apple Game Center; purchases, restoration, and code redemption use Apple’s services and require a connection.

Are there ads?

The current version has no advertising. Optional rewarded ads are planned, but are not available in the current version. Any advertising and privacy changes will be explained before that update.
